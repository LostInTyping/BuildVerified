## Overview

Ohio Offense Code Portal is a standalone application that houses all of Ohio offense codes. OCP served as a companion to the Ohio Sentencing Data Platform (OSDP), feeding accurate, up-to-date offense codes into the sentencing data ecosystem. The application was actively maintained by lawyers assigned to it by the Ohio Criminal Sentencing Commission.

## Client

Ohio Criminal Sentencing Commission | Supreme Court of Ohio

React, Node.js, Express, PostgreSQL, MongoDB, TypeScript
